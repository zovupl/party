# 🎉 Party App

Интерактивная игровая платформа для вечеринки на 6 человек. Все заходят на один
сайт с телефонов, синхронизация в реальном времени через Firebase. Мини-игры,
квизы, общая таблица очков, админ-панель.

**Живая ссылка:** https://zovupl.github.io/party/

---

## Как это работает

- **Игроки** заходят по ссылке, выбирают имя, ждут, пока админ запустит игру.
- **Админ** (ты) — долгое нажатие на логотип `🎉 PARTY` → ввод пароля → панель управления.
- Весь контент игр (вопросы, слова, задания) хранится **в Firebase, а не в коде**,
  поэтому подсмотреть ответы в исходниках сайта нельзя.

## Первый запуск (один раз)

### 1. Включи вход по Email/Password в Firebase
Firebase Console → проект `party-app-18f63` → **Authentication** → Get started →
вкладка **Sign-in method** → включи **Email/Password**.
*(Это нужно, чтобы только у тебя был доступ к базе вопросов.)*

### 2. Создай админа и залей контент
В папке проекта выполни (замени `МОЙ_ПАРОЛЬ` на свой — им ты будешь входить в админку):

```powershell
# PowerShell
$env:ADMIN_PASSWORD="МОЙ_ПАРОЛЬ"; node seed/seed.mjs
```
```bash
# или bash
node seed/seed.mjs МОЙ_ПАРОЛЬ
```

Скрипт создаст админ-аккаунт `admin@zovu.pl` с этим паролем и зальёт все вопросы в базу.
**Пароль нигде в коде не хранится — запомни его.**

### 3. Ужесточи правила безопасности
Firebase Console → **Realtime Database** → вкладка **Rules** → вставь содержимое
файла [`database.rules.json`](database.rules.json) → **Publish**.
Теперь база вопросов доступна только админу, а test mode больше не нужен.

### 4. Включи GitHub Pages
Репозиторий `zovupl/party` → **Settings** → **Pages** → Source: **Deploy from a branch**,
Branch: **main** / `(root)` → Save. Через минуту сайт будет на
https://zovupl.github.io/party/

## Что где менять

| Что | Файл | Строка |
|-----|------|--------|
| **Имена игроков** | `js/config.js` | `players: [...]` |
| **Пароль админа** | не в коде — задаётся при `seed.mjs` (можно сменить в Firebase → Authentication) |
| **Email админа** | `js/config.js` (`adminEmail`) + `database.rules.json` (в двух местах) — должны совпадать |
| **Время на вопрос / очки** | `js/config.js` (`quizTime`, `quizBasePoints`, `quizSpeedBonus`) |
| **Вопросы, слова, задания** | `seed/content.json` → перезалей `node seed/seed.mjs <пароль>` |
| **YouTube ID треков** | `seed/content.json` → блок `tracks` → поле `videoId` |

После правки `content.json` заново запусти `node seed/seed.mjs <пароль>`, чтобы обновить базу.

## Игры

1–5. **Квизы** — Гарри Поттер, Звёздные войны, Нолан, Сумерки, «Насколько ты умён»
(таймер, очки за скорость как в Kahoot). 6. Угадай мелодию (баззер). 7. Кто из нас…
8. Я никогда не… / Выпей, если… 9. Рулетка фантов. 10. Кто это написал? 11. Крокодил.
12. Кто я? 13. Алиас.

## Структура данных Firebase

```
/state/activeGame   — текущая игра (пишет только админ; игроки видят вопрос БЕЗ ответа)
/state/showLeaderboard
/players/<имя>       — присутствие
/scores/<имя>        — очки (пишет админ)
/answers, /votes, /buzzer, /texts, /sins — ответы игроков по раундам
/content             — все вопросы/слова/задания (только админ)
```

## Стек

Vanilla JS + ES-модули (без сборки), Firebase Realtime Database через CDN.
Хостинг — GitHub Pages. Тёмная тема, mobile-first.
